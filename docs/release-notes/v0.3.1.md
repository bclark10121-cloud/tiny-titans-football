# Tiny Titans Football v0.3.1

A standards release. No new football. It adds tester tools, a proper app icon and a new home for the source.

## New in this version

- Tester tools. Settings has a new button at the bottom: Tester tools. It asks for a code. Enter it by touch, on a keyboard or with only an Xbox controller. A red DEBUG tag shows at the top left while the tools are unlocked. The unlock ends when the game closes.
- Tools for a game in progress: Home score +7, Away score +7, Quarter (1 to 4), Clock to 10 seconds and Final play (4th quarter, clock at zero).
- Tools for the season: New season at week 1, Jump to week 4, Jump to week 6 and Jump to the Title Game. The computer plays the weeks in between.
- Other tools: Difficulty, Pretend camera notch, Reset the save, Load the test save, a frame rate and memory readout and Game speed (x1, x2, x4).
- App icon. The Android icon now fills the phone's icon shape, round or square. Themed icons on Android 13 and later show a football.
- The source moved to a private repo. This public repo keeps the game page, the builds, these notes and the backlog. The line under the buttons no longer links to the source.
- Fixed: one project file still said version 0.2.0.

## Shared kit

Built with kit 1.6.0. This game is the first to use it.

## Install

v0.3.1 installs over v0.3.0 and v0.2.0. Your saved games and season stay. If you still have v0.1.0, uninstall it first. It used a test signature.

## Test checklist

1. Install the APK over v0.3.0. The home screen icon shows the football on turf with no white box round it.
2. Open the game. The title card says v0.3.1. Your record and any saved game are still there.
3. Open Settings. Scroll to the bottom. Press Tester tools. A code pad opens.
4. Enter a wrong code. Nothing opens. Press Clear.
5. Enter your code. The tools list opens and a red DEBUG tag shows at the top left.
6. Press Game speed. It steps x2, x4, then back to x1.
7. Switch on Frame rate and memory readout. A green line shows under the DEBUG tag. Switch it off.
8. Press Jump to the Title Game. The season screen shows your team at 6 and 0 with Play the Title Game.
9. Play the Title Game. Open Settings, Tester tools. No code is asked this time.
10. Press Home score +7. The scoreboard goes up by 7.
11. Press Final play. After the next play the game ends.
12. Press Load the test save. The title card shows a record of 12, 5 and 1 and a season at week 6.
13. Press Reset the save. The record is 0, 0 and 0 and the season is gone. Settings such as Music stay.
14. Close the game and open it again. Tester tools asks for the code again.
15. With an Xbox controller only: open Settings, move to Tester tools, press A, enter the code with the D-pad and A. B closes the tools.
16. In the browser: the same steps work from the game page with a keyboard. Type the code on the number keys.
