# Tiny Titans Football v0.3.2

A standards release. No new football. One Settings menu and five save slots, the same way every game will have them.

## Five minute test

1. Install the APK over v0.3.1. Open the game. The title card says v0.3.2 and has a new button: Slot 1.
2. Your record and any season from v0.3.1 are still there. They are now slot 1.
3. Open Settings. Music is the first button. Press it: Full, Off, Low, Medium, High, Full. The music follows.
4. Press Frame rate. A small green number shows at the top left. Press it again to hide it.
5. Go to the title card and press Slot 1. The list shows five slots. Press Slot 2. The title card now says Slot 2 with a record of 0-0-0.
6. Press Slot 2, then Delete on slot 2. It says Press again. Press it. Slot 2 is Empty and the game is back on slot 1.
7. Close the game and open it again. Your Settings changes are still there. Nothing asked you to save.

## New in this version

- Settings, the same in every game from now on. Music and Sound in five levels. Full screen (browser only). Frame rate number. Rumble (phone buzz and controller rumble, shown on a phone or with a controller connected). Then this game's own: Auto pass, Players, Quarter length and Controls. Then Text size (Normal, Large, Larger) and Reset settings.
- Auto save. Every setting saves the moment you change it. There is no Save button.
- Five save slots. Each slot has its own record, season and game in progress. The Slot button on the title card opens the list.
- Delete a slot with two presses. If you delete the slot you are playing, the game moves to another slot.
- Settings are kept apart from the slots. Deleting a slot never changes them.
- Reset settings also needs two presses.
- Sound effects is now called Sound. Vibration is now called Rumble.
- Tester tools is now the last button in Settings.

## Shared kit

Built with kit 1.7.0. This game is the first to use it.

## Install

v0.3.2 installs over v0.3.1, v0.3.0 and v0.2.0. Your saved games and season stay. If you still have v0.1.0, uninstall it first. It used a test signature.

## Full test checklist

1. Settings fits the screen on a phone, a tablet and a desktop browser window. The list scrolls.
2. Set Text size to Larger. Every screen still fits. Set it back to Normal.
3. Sound: Off silences the crowd and hits. Music: Off silences the music.
4. Rumble: Off stops the buzz on a tackle.
5. In the browser, Full screen: On fills the screen. Esc leaves it.
6. Controls opens How to play. B or Back returns.
7. Change three settings, then press Reset settings twice. All go back to their first states.
8. With an Xbox controller only: open Settings, change Players, close with B. Open the slot list, move to a Delete button with the D-pad, close with B.
9. Start a season in slot 1. Switch to slot 3. Its Season button says Season, not a week. Switch back to slot 1. The season is where you left it.
10. The slot list shows each slot's record and season on its second line.
11. Tester tools still opens with your code from the bottom of Settings.
