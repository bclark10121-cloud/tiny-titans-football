# Tiny Titans Football v0.3.3

A standards release. No new football. Hints that follow your device, a pause when the controller drops, Copy bug report and a privacy page.

## Five minute test

1. Install the APK over v0.3.2. The title card says v0.3.3. Your slots and settings are still there.
2. On the phone the title card shows the Touch controls only. Connect an Xbox controller and press a button: it changes to the Controller controls.
3. Start an exhibition with the controller. The hint before the snap reads "Snap: A.  Audible: Y". Touch the screen once: it names the Snap button.
4. Mid-game, turn the controller off. The Menu opens and a line says the controller disconnected. The clock has stopped.
5. The Menu now reads Resume, Settings, How to play, Restart, Title.
6. Open Settings, Tester tools, enter your code, press Copy bug report. Paste into any app. You get the version, the device, where you were in the game, the slot and the settings.
7. On the game page, scroll to the bottom and open Privacy.

## New in this version

- Hints follow the device you used last. A key press shows keys, an Xbox controller button shows Xbox button names and a touch shows the touch buttons. The title card does the same with its controls.
- The game pauses when the controller in use disconnects mid-game, the same as when the app loses focus.
- The Menu button Help is now How to play, the same name and place every game will use.
- Copy bug report in Tester tools: one press copies the version, the device, the place in the game, the slot and the settings as text.
- A privacy page. The game collects no data and the Android app does not ask for the internet permission.
- Every release now has a GitHub Release with its APK. The game page keeps the newest two APKs.

## Shared kit

Built with kit 1.8.0. This game is the first to use it.

## Install

v0.3.3 installs over v0.3.2 and earlier, back to v0.2.0. Your slots, saved games and settings stay.

## Full test checklist

1. Keyboard in the browser: the title card shows the Keyboard controls. The snap hint reads "Snap: Space.  Audible: R".
2. On a pass play the hint adds the hot route line for your device.
3. The kick meter hint says Press Space, Press A or Tap to match your device.
4. Lose focus mid-game (switch apps). The Menu opens, as before.
5. With the controller off, the game still plays by touch after you close the Menu.
6. Copy bug report at the title card says Place: Title card. In a game it names the quarter, the clock, the score and the down.
7. The privacy link at the bottom of the game page opens and links back.
8. Older versions are on the repo's Releases page, each with its APK.
