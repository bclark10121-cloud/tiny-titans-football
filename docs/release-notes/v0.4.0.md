# Tiny Titans Football v0.4.0

A new start screen, the same layout in every game on The Game Shelf (standard G5.21). Nothing else in the game changed.

## Five minute test

1. Install the APK over v0.3.5. Your saves stay.
2. Open the game. The start screen is a painted scene: a stadium under the lights, a full crowd, the goalposts and a ball on its tee. It moves gently.
3. The title glows softly. Under it: one line of controls for what you used last, then Continue (a game in progress), Play (the slot list, then Exhibition or Season) and Settings. Version 0.4.0 sits at the bottom.
4. Press Play. Play opens the slot list, then a new How do you want to play screen with Exhibition and Season. B goes back to the title card. The Exhibition, Season and Slot buttons left the title card.
5. Press B or Back to return to the start screen. Up and down on the D-pad move between the buttons and wrap round.

## New in this version

- The shared start screen from kit 1.10.0 with this game's own painted scene, drawn in code.
- Buttons stacked in one column: gold for the first, dark glass for the rest, one focus ring. Continue shows only when there is something to continue.
- Music credits, tips and long key lists left the start screen. They live in Settings, About and How to play.
- Play opens the slot list, then a new How do you want to play screen with Exhibition and Season. B goes back to the title card. The Exhibition, Season and Slot buttons left the title card.
