# Tiny Titans Football v0.5.2

Release 7: the standards review pieces every game now shares. A Records page, button remapping with Hold or Toggle for Sprint, backup codes, a picture setting and steadier sound levels. The new players, run cycle, celebrations and "Stage 3" music from v0.5.0 and v0.5.1 stay as they are.

## Five minute test

1. Install the APK over v0.5.1. Your saves stay.
2. Press Play, pick your slot, pick Exhibition and play a game to the end. A gold note says "Achievement: Kickoff".
3. Open the Menu. Press Records. It lists 10 achievements with progress, then your stats: games, wins, losses, ties, seasons and titles.
4. Open Settings, then Change controls. Pick Burst and press another key or button. If another action had it, the two swap. Set Sprint to Toggle and try a run. Reset controls puts everything back.
5. In Settings, try Picture Low, Medium and High, and Battery saver.
6. Open the slot list. Press Copy code on your slot. Paste it into the box under the slots on another device and press Load code.
7. Listen to the crowd. It should sound as before.

## New in this version

- Records in the Menu: 10 personal achievements (two hidden) and 6 stats (G4.10, G4.11).
- Change controls in Settings for move, snap, juke, dive, audible, sprint, burst and switch. Sprint can be Hold or Toggle (G5.22, G5.23). Passing stays on each receiver's button.
- Picture (Low, Medium, High) and Battery saver in Settings (G6.12).
- Backup codes in the slot list: Copy code and Load code (G5.19).
- Old saves are now tested every release (G5.24).
- An error log on the device. Copy bug report in Tester tools adds the last ten errors (G5.27).
- Crowd and cheer files brought to one loudness level (G5.28), with the crowd player set to keep the same mix.
