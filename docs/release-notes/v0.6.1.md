# Tiny Titans Football v0.6.1

Start screen music. "Rock on Chicago" by Kevin MacLeod: It already had its own title track. Now it starts as soon as the start screen shows on Android, without a tap.

## Five minute test

1. Install the APK over v0.6.0. Your saves stay.
2. Open the game on Android. The title track starts as soon as the start screen shows, with no tap.
3. In a browser, tap or press any key once. The title track starts. Browsers block sound until the first tap.
4. Turn Music off in Settings. The title track stops. Turn it back on.
5. Tap Play. The title track keeps playing through team select.

## New in this version

- Start screen music (G5.21): "Rock on Chicago" by Kevin MacLeod now starts on Android without a tap.
- On Android and desktop the music starts with the start screen. In a browser it starts on the first tap, click, key or button press.
- No two games share a title track.
