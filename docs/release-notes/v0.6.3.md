# Tiny Titans Football v0.6.3

A new start screen title. The name now sits in the middle of the screen, above the buttons, in its own font: Graduate. It sizes itself to the screen and moves onto two lines on a narrow phone when it needs to.

## Five minute test

1. Install the APK over v0.6.2. Your saves stay.
2. Open the game held upright. The name sits in the middle of the screen in Graduate, with the tag line under it. The buttons stay along the bottom.
3. Turn the phone sideways. The name stays centered above the buttons. It never covers a button.
4. Open the game page. The game name at the top uses the same font.
5. Press Play. The game starts as before.

## New in this version

- Start screen title (G5.21 Title, asked for by BC on 2026-11-18): the title sits in the dead center of the screen, always above the buttons, about 80 percent of the screen wide.
- The title font is Graduate (SIL Open Font License 1.1), picked by BC from three options on 2026-11-18. No two games share a title font.
- The game page and the Game Shelf card show the name in the same font.

## Shared kit

Kit 1.15.0: `title_screen.gd` centers and sizes the title. `build_page.py` ships the title font with the game page.

## Install

Version 0.6.3 installs over 0.6.2 and keeps your saves.

## Test checklist

- [ ] Upright: the name is centered and fills most of the width.
- [ ] Sideways: the name is centered above the buttons.
- [ ] The name never covers the controls line or a button.
- [ ] The game page name uses Graduate.

## Tested and not tested

Tested on the cloud test machine: the start screen upright (720 x 1280) and sideways (1280 x 720), with a check that the title is centered and clear of the buttons.

Not tested: a real phone or the Retroid. Look once on a phone both ways.
